# Security policy

Report suspected vulnerabilities privately to `happy518596@gmail.com`. Do not open
a public issue until a fix is available. Include affected versions, reproduction
steps, and impact. Supported releases are the latest minor release and its immediate
predecessor.

The loader treats PPTX files as untrusted ZIP/XML input. Security reports involving
path traversal, decompression limits, external relationships, or unsafe asset links
are prioritized.
